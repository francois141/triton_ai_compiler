# Pi agent

This folder contains a Pi-based agent. Pi is an existing agent harness, like Codex or Claude Code, that supports most existing models and API. Re-using Pi makes it super easy to support any model we want to.

## Setup

Copy the PTX skills of your choosen version into into `agent_workspace/ptx_skill/`.

Example: from this folder

```sh
cp -r ../skills/ptx_skills/ptx_skill agent_workspace/ 
```
